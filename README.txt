FraudShield Web3 website (local copy)

To view it on this computer:
1. Open a terminal in this folder.
2. Run:  python -m http.server 8000
   (on some Macs: python3 -m http.server 8000)
3. Open Chrome and go to:  http://localhost:8000
4. Press Ctrl+C in the terminal to stop the server.

The Download buttons give visitors FraudShield-Web3-v0.10.1.zip from this folder.
